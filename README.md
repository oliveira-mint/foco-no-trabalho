🎧 Foco no Trabalho — Versão 1.0.0
Aplicativo nativo para Linux desenvolvido em Python com interface GTK4 / Libadwaita. Projetado para ajudar na concentração e produtividade através de sons ambientais personalizáveis.

✨ Recursos
🎵 Sons ambientais variados: Chuva, trovão, cafeteria, lareira, riacho, vento, pássaros, teclado e música lo-fi.
🎚️ Controle individual de volume: Misture diferentes sons no nível que preferir.
app
🎨 Interface Nativa: Visual moderno e integrado ao ecossistema GNOME / Linux Mint.
📦 Como Instalar (Flatpak)
Baixe o arquivo foco-no-trabalho.flatpak na seção Assets abaixo.
Abra o terminal na pasta onde fez o download (ex: cd ~/Downloads).
Execute o comando de instalação:
flatpak install foco-no-trabalho.flatpak
