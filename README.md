# 🎧 Foco no Trabalho

Aplicativo nativo para Linux desenvolvido em Python com interface GTK4 / Libadwaita. Projetado para ajudar na concentração e produtividade através de sons ambientais personalizáveis e temporizador de foco.

---

### ✨ Recursos
* 🎵 **Sons ambientais variados:** Chuva, trovão, cafeteria, lareira, riacho, vento, pássaros, teclado e música lo-fi.
* 🎚️ **Controle individual de volume:** Misture diferentes sons no nível que preferir.
* 🎨 **Interface Nativa:** Visual moderno e integrado ao ecossistema GNOME / Linux Mint.

---

### 📦 Como Instalar (Flatpak)

1. Vá até a seção **[Releases](https://github.com/oliveira-mint/foco-no-trabalho/releases)** e baixe o arquivo **`foco-no-trabalho.flatpak`**.
2. Abra o terminal na pasta onde fez o download (ex: `cd ~/Downloads`).
3. Execute o comando de instalação:

```bash
flatpak install foco-no-trabalho.flatpak
